# The Upgrade Tree

A public tracker of how much of a human being we can change on purpose today, and of the idea that humans keep up with advanced AI by merging with it. A Sentient Horizons project, sibling of The Belt Equation (beltequation.com) and The Quiet Galaxy. Site: theupgradetree.com. Kicked off 2026-10-16; the project record lives in TimeAssembler.
